# Lumet 2025

[источник] Eliott Lumet, Mélanie C. Rochoux, Thomas Jaravel, Simon Lacroix, "Surrogate-based ensemble data assimilation for reducing uncertainty in large-eddy simulation of microscale pollutant dispersion", Building and Environment, 2025.
[источник] Аннотация: This study develops a surrogate-based ensemble data assimilation framework to reduce uncertainty in large-eddy simulation of microscale pollutant dispersion, using a surrogate model to accelerate the ensemble Kalman filter.
[порождено] Зачем проекту: суррогатная ансамблевая ассимиляция данных для LES микромасштабного рассеяния примеси — продолжение работы Lumet 2024, прямо по теме проекта.
