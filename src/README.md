# `src/` — планируемые модули статьи

Существующий файл `hw2_uncertainty.py` сохранён без изменений.

На этом этапе код baseline не реализуется: физические допущения ещё не
подтверждены автором. После подтверждения здесь планируются:

- `gaussian_baseline.py` — стационарная гауссова модель в духе ISC3
  (точечное ядро, отражение от земли, коэффициенты Briggs, площадной источник);
- `compare_centroids.py` — парное сравнение `e_Gaussian − e_DL`, описательные
  статистики и bootstrap;
- при необходимости — общие функции метрик, совместимые с
  `checks/check_hw2.py`.

Требования к эксперименту — `research/problem.md`. Не добавлять пороги
приёмки нового метода.
