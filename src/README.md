# Модель рассеяния

Существующий файл `hw2_uncertainty.py` сохранён без изменений.

`gaussian_baseline.py` вычисляет стационарное гауссово поле в духе ISC3.
Ядро суммирует вклады площадных элементов, учитывает отражение от земли и
использует городские коэффициенты Briggs для класса D.

Исходные допущения и область применения описаны в
[постановке исследования](../research/problem.md). Команда запуска и
происхождение входов приведены в [описании эксперимента](../experiment/README.md).
