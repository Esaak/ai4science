## 1. Задача и место верификатора

Проверяется, насколько точно нейросетевой суррогат `combined_family_ft_best` предсказывает
положение концентрационно-взвешенного центра шлейфа примеси PM2.5 над городским кварталом
по сравнению с LES-расчётом. Выбор задачи — решение пользователя: проверка идёт на 25 новых
планировках (`geometry_id` 150–174, `dir_k=0`, `tracer=1`, слой Z1 = 3 м), не входивших в
обучение модели. `dir_k=0` — один индекс направления ветра, не штиль.

Верификатор проверяет именно положение центра, потому что это практически важный и
чувствительный к ошибке кусок задачи: небольшой сдвиг шлейфа легко ломает поточечные метрики,
тогда как центр концентрации описывает, куда направлен шлейф и служит положением
концентрационно-взвешенного поля. Если в этом куске
ошибка, вердикт о модели будет принят ошибочно. Общий вывод обоснован только на этих 25
сценах, не на всей валидации.

## 2. Методика

Методика записана в `METHOD.md` до первого прогона учебного агента: коммит `e5755bd`
(2026-11-14 18:29). Замысел — проверить правило принятия (раздел 7 METHOD): медианная
евклидова ошибка центра ≤ 10 м И минимум 20 из 25 ошибок ≤ 20 м. Пороги выбрал пользователь
после того, как увидел внутренний пилот ИИ-ассистента на тех же сценах; методика не является слепой
предварительной регистрацией — это зафиксировано в разделе 10 METHOD.

Что меняется — 25 планировок; что фиксируется — модель `combined_family_ft_best`, уровень
Z1 (3 м), штатная маска валидных ячеек по высоте здания без 5%-го порога, размер ячейки
2×2 м, сетка 128×128. Входной архив `fixtures/hw2/plumes.npz` и `manifest.json` подготовил
ИИ-ассистент из двух чекпойнтов и LES (архивы и данные — не работа учебного агента). Новая выборка
`build_dataset_v1` имеет осаждение; «без осаждения» в отчёте не указывается.

## 3. Верификатор

- **Что проверяет:** правило принятия для `combined_family_ft_best` на 25 сценах (
  `checks/check_hw2.py`).
- **Как устроен:** семь синтетических тестов на свойствах (аддитивность площадного
  интеграла, инвариантность к масштабу, корректность маски, смещение на одну ячейку, поворот
  на 90°, нулевое поле, одиночная ячейка) плюс маршрутный расчёт ошибок по 25 сценам из
  архива. Код написал и
  расчёт выполнил учебный агент (Гусь) после методики.
- **Чего не проверяет:** инференс из чекпойнтов (локальная команда не
  повторяет инференс), другие направления ветра, трассеры и планировки за пределами 25 сцен,
  воспроизводимость на других версиях Python/NumPy.

| № | Свойство | Почему должно выполняться | Тест |
|---|---|---|---|
| 1 | Аддитивность интеграла | площадной интеграл линейный | c1+c2 непересек. — Σ равен сумме |
| 2 | Инвариантность центра к масштабу | центр не зависит от нормировки | центр поля c и k·c совпадает |
| 3 | Корректность маски | маска исключает невалидные ячейки | аномалия под маской не влияет |
| 4 | Смещение на 1 ячейку | центр смещается на X+2, Y без изменения | сдвиг +1 по X даёт центр (X+2, Y) |
| 5 | Поворот на 90° | центр не инвариантен к повороту | точное (x,y)→(y,256−x) |
| 6 | Нулевое поле | центр не определён | поднят `ValueError` |
| 7 | Одиночная ячейка | центр совпадает с центром ячейки | ячейка (row=3,col=4) даёт центр (x=9,y=7) |

## 5. Результаты прогона

Основная команда `.venv/bin/python checks/check_hw2.py` дала код 0. Результат
`results/hw2/summary.json`: current медиана 8.044579862 м, 21/25 ошибок ≤ 20 м, средняя
ошибка 13.126136 м, максимум 55.447557 м. По заранее записанным порогам модель **принята**
(медиана ≤ 10 И ≥ 20 сцен ≤ 20 м).

Сравнение с базовой линией `v1_only_long_best` (описательное):

| Вариант | Медиана (м) | Доля сцен ≤ 20 м |
|---|---|---|
| current `combined_family_ft_best` | 8.0446 | 21/25 |
| базовая линия `v1_only_long_best` | 8.0131 | 20/25 |

Базовая линия обучалась не просто без канала семейства, но и на другом наборе данных.
Current по медиане чуть хуже baseline (8.04 против 8.01), но по доле сцен ≤ 20 м лучше
(21 против 20). Различие внутри практических порогов; отрицательный результат по
превосходству над baseline допустим и пороги не меняются.

## 7. Воспроизведение

```bash
git clone <репозиторий> && cd pm25_surrogate && git checkout hw2
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python checks/check_hw2.py
```

Окружение: Python 3.14.4, NumPy 2.5.4. Команда `pip install -r requirements.txt` — инструкция к
воспроизведению; в чистом клоне NumPy `2.5.4` фактически ставился напрямую, этот факт выше не
смешивается с инструкцией. Время выполнения отдельно не измерялось.
Данные: архив `fixtures/hw2/plumes.npz` и `manifest.json` приложены к репозиторию
(подготовлены ИИ-ассистентом). Чистый локальный клон на коммите `0fd67be` воспроизвёл код 0:
медиана 8.04 ≤ 10, 21/25 ≤ 20; подробности в `results/hw2/clean_clone.txt`.

## 8. Ограничения

- Верификатор не повторяет инференс из чекпойнтов — работает на готовом архиве; при смене
  чекпойнтов или версий данных результат может отличаться. Осаждение в новой выборке учтено,
  но отдельно не варьировалось.
- Вывод распространяется только на 25 сцен (`geometry_id` 150–174, `dir_k=0`, `tracer=1`),
  уровень Z1; другие ветры, трассеры и планировки не проверены.
- Пороги выбраны после пилота ИИ-ассистента — правило принятия не слепая предварительная
  регистрация. Базовая линия обучалась на другом наборе.
- Эта работа не доказывает качество модели на всей val и не является оценкой безопасности
  PM2.5; право публикации полей архива не подтверждено.
