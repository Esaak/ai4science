# Парное сравнение ошибок центра шлейфа

## Назначение

Скрипт `compare_centroids.py` связывает результаты LES и DL с гауссовым baseline и даёт одну строку ошибок на сцену. [Скрипт](compare_centroids.py) · [Постановка задачи](../research/problem.md) · [Методика ДЗ2](../METHOD.md) · [Гауссов baseline](../src/baseline.md)

## Входы

- Для сравнения из `../fixtures/hw2/plumes.npz` берутся массивы `geometry_id`, `scene_name`, `les`, `current` (поле DL) и `valid`.
- `../fixtures/hw2/manifest.json` — SHA-256 архива и исходных сцен.
- `gaussian_inputs.json` — геометрия и относительные мощности боксов, `g` из первых двух компонент `wind`, которые задают направление градиента давления, ключи сцены, `dir_k`, `tracer`, SHA-256 оригинала.
- `gaussian_config.json` — протокол, включая высоты, отсечку и выбор слоя Z1 (индекс слоя 0).

Источник боксов — `meta.source_boxes`, мощности — `(x1 − x0) × (y1 − y0)² × 8 м × meta.emis_coeff`. Входы подготовлены отдельно. Их происхождение и проверка растра мощности описаны в инструкции к эксперименту. [Описание входов](README.md#входы)

## Порядок работы

Сначала выполняются синтетические проверки ядра и разбиения. Затем `verify_archive` из `../checks/check_hw2.py` проверяет хеш сохранённого архива, схему и массивы. Далее скрипт индексирует оба набора по паре `(geometry_id, scene_name)`, проверяет дубликаты и точное совпадение множеств ключей, а у всех сцен проверяет настройки (`dir_k=0` и `tracer=1`) и хеши исходных сцен по манифесту. В сравнении 25 сцен с `geometry_id` 150–174. Сортировка выполняется по паре ключей.

## Построение гауссова поля

Границы ячеек строятся из `X` и `Y` с отступом на половину шага. Каждый бокс пересекается с ячейками сетки, включая частичные пересечения. Элемент в центре пересечения получает вес `Q_бокс * A_пересечения / A_бокса`. Сумма весов элементов равна мощности бокса. Вклады разных боксов суммируются.

Центр, взвешенный по полю, вычисляется как

`c = Σ(r · C) / Σ(C)`

по валидным ячейкам, где общая площадь ячейки сокращается. Один и тот же `valid` в слое Z1 применяется к трём полям. Вычисления выполняются в float64. Скрипт проверяет конечность и неотрицательность гауссовых весов, положительную конечную сумму по маске и конечность ошибок.

## Метрики

Используются `compute_concentration_center` и `euclidean_error` из верификатора. `e_DL` и `e_Gaussian` — евклидовы расстояния до центра LES в метрах. Разность `d = e_Gaussian − e_DL`. При `d > 0` меньше ошибка DL, при `d < 0` меньше ошибка Gaussian.

## Запуск

Команда из корня репозитория

```bash
.venv/bin/python -m experiment.compare_centroids
```

`--pilot` печатает первую отсортированную сцену и её сумму гауссовых весов по маске без записи. `--output-dir PATH` выбирает каталог вывода. Локальный запуск использует сохранённые входы.

## Выходные файлы

По умолчанию пишутся [paired_errors.csv](results/paired_errors.csv) и [provenance.json](results/provenance.json). CSV содержит `geometry_id,scene_name,e_DL,e_Gaussian,d`. Ошибки и разность записываются с 12 десятичными знаками. `provenance.json` содержит SHA-256 CSV, входов и трёх Python-файлов, версии Python и NumPy. Файлы готовятся во временном каталоге и заменяются по отдельности.
