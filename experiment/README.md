# `experiment/` — планируемый прогон статьи

Численных результатов на этом этапе нет.

После подтверждения автором допущений A1–A7 здесь планируются:

- зафиксированная конфигурация гауссова baseline;
- команда запуска парного сравнения на 25 сценах (`geometry_id` 150–174,
  `dir_k=0`, `tracer=1`, Z1);
- в `results/` — таблица парных ошибок со столбцами `geometry_id`, `scene_name`,
  `e_DL`, `e_Gaussian`, `d`, сводка и рисунок по одному прогону;
- журнал окружения и хешей кода.

Для включения результатов в статью необходима верификация кода и результатов
автором.

Протокол и ограничения — `research/problem.md`. Порогов приёмки нового метода
не вводить.
