# Воспроизведение парного сравнения

Из корня репозитория с установленными зависимостями:

```bash
.venv/bin/python -m experiment.compare_centroids
```

Скрипт прогоняет синтетические проверки и сохраняет `results/paired_errors.csv`
и `results/provenance.json` в этом каталоге. `--pilot` считает только
`geometry_id=150` и печатает результат. Для повторного полного прогона в отдельный
каталог можно передать `--output-dir PATH`. Интернет и SSH для расчёта не нужны.

## Входы

- LES, DL и общая маска слоя Z1 взяты из `../fixtures/hw2/plumes.npz`.
  Скрипт проверяет архив по манифесту ДЗ2, затем сопоставляет сцены по паре
  `(geometry_id, scene_name)` и сверяет SHA-256 исходных сцен. Для всех
  25 сцен сохранённая маска совпала с маской по высотам зданий в исходных
  файлах.
- `gaussian_inputs.json` получен из 25 исходных файлов в
  `urban_layer_v1_npz/val` на `edison`. Первые две компоненты `wind`
  задают направление градиента, их совпадение с каналами входа проверено
  по каждой сцене. Перенос направлен против градиента. Направления из
  `wind` и из `meta.dPdx` / `meta.dPdy` различаются максимум на 0,303°
  по этой выборке.
- Границы дорожных боксов взяты из `meta.source_boxes`. Веса рассчитаны
  как `(x1 − x0) × (y1 − y0)² × 8 м × meta.emis_coeff` по конфигурации
  LES и `get_maps_v1.py::source_maps`. Проверка восстановила исходный
  растр `power`, включая суммирование в пересечениях. Для расчёта поля
  мощность каждого бокса распределяется по пересечениям бокса с ячейками,
  пропорционально площади пересечения. Точечное ядро помещается в центр
  каждого пересечения.
- В `gaussian_config.json` записаны настройки утверждённого протокола.

По каждой из 25 сцен таблица содержит ошибки центра в метрах
`e_DL`, `e_Gaussian` и их разность `d = e_Gaussian − e_DL`. Метаданные
прогона содержат хеши входов, кода и таблицы, версии Python и NumPy.
Протокол и ограничения описаны в [постановке исследования](../research/problem.md).
Перед включением результатов в статью требуется верификация автора.

## Сводная статистика и рисунок

Для шага 4 установите Matplotlib в окружение эксперимента. Версии первого
прогона — Python 3.14.4, NumPy 2.5.4 и Matplotlib 3.11.2.

```bash
.venv/bin/python -m pip install matplotlib==3.11.2
.venv/bin/python -m experiment.analyze_pairs
```

Команда проверяет хеш и состав таблицы, затем из тех же 25 пар сохраняет
`results/summary.json` и векторный `results/paired_errors.pdf`. Статистика
включает среднюю парную разность Gaussian − DL, 95% парный bootstrap-интервал,
медианы и число ошибок ≤ 20 м. Параметры bootstrap зафиксированы в
[протоколе](../research/problem.md). JSON содержит версии среды и SHA-256
таблицы, скрипта и PDF.

Для повтора из сохранённых полей в отдельный каталог выполните из корня
репозитория:

```bash
out=$(mktemp -d)
.venv/bin/python -m experiment.compare_centroids --output-dir "$out" && \
  .venv/bin/python -m experiment.analyze_pairs --input-dir "$out" --output-dir "$out"
```

## Двухпанельный рисунок для статьи

```bash
.venv/bin/python -m experiment.plot_paper_figure
```

Команда сохраняет `results/paper_figure.pdf` шириной 6,75 дюйма. Слева
показаны разности Gaussian − DL для всех 25 планировок в порядке
возрастания. Справа — карты LES, Gaussian и DL на сценах с наибольшей
положительной и отрицательной разностями (168 и 167). Все карты
показывают одну область 256 × 256 м в слое Z1. Каждое поле нормировано
на сумму по валидным ячейкам, цвета сопоставимы по общей логарифмической
шкале. Модуль проверяет ошибки центров примеров по исходной таблице пар.

## Сборка черновика статьи

Из корня репозитория:

```bash
.venv/bin/python -m experiment.make_paper_numbers
.venv/bin/python -m experiment.make_paper_numbers --check
(cd paper && tectonic -X compile paper.tex)
```

Первая команда пишет макросы чисел в `../paper/results.tex` из сохранённых
`results/summary.json` и `results/paired_errors.csv`, вторая только сверяет
их. Сборка проверена на Tectonic 0.17.0; при первом запуске нужен локальный
кэш пакетов или сеть. Исходные CSV/JSON и сохранённый `results/paper_figure.pdf`
достаточны для сборки, полный эксперимент выполняется командами выше.

Рисунок при необходимости пересобирается отдельно:

```bash
.venv/bin/python -m experiment.plot_paper_figure
```

Требуется Matplotlib 3.11.2, как указано в разделе о рисунке для статьи.

Итоговые файлы: [PDF](../paper/paper.pdf) и [исходник](../paper/paper.tex).
