Abstract—CFD (Computational Fluid Dynamics) solvers
have been very popular for ﬂuid ﬂow simulation which has been
proved to be imperative to solve modern problems relating to
analysis, design, and optimization in the ﬁeld of aerodynamics.
Nevertheless, CFD simulations are usually memory intensive
and computationally demanding, iterative time-consuming pro-
cesses. Such drawbacks often affect productivity and limit the
design space exploration and forbid interactive design. The
real-time prediction of ﬂuid ﬂow helps us to overcome these
drawbacks. There have been many successful implementations
of the application of Deep Neural Networks for the ﬂuid ﬂow
prediction. Especially until now, CNNs (Convolutional Neural
Networks) have been proven to be cutting edge solution for
such approximations. However, CNN poses some challenges. We
propose a new ﬂuid ﬂow approximation model for prediction
of velocity ﬁeld in non-uniform steady laminar ﬂow based on
Capsule Neural Networks.
I. I NTRODUCTION
For the simulation of the physical interaction of ﬂuids with
surfaces, CFD (Computational ﬂuid dynamics) analysis is
required, which performs the necessary calculations deﬁned
by boundary conditions. This calculation is carried out with
the help of partial differential equations, e.g. the popular
Navier-Stokes equations for ﬂuid ﬂow. Here in this work
we have focused on non-uniform steady laminar ﬂow. In the
early stages, designers typically need to make preliminary
design decisions by iterating over various designs. For
this they don’t need highly accurate and precise design
simulations which are time consuming and computationally
expensive, but rather an approximate design that would help
in necessary decision making. Thus, for this process, we
would not need highly accurate and precise CFD methods.
The simulation time may extend up to days and weeks for
complex systems, affecting productivity and efﬁciency.
This can be achieved by using data-driven surrogate mod-
els that produce quick approximation results. Deep Neural
Networks have been proved to be the most efﬁcient data-
driven surrogate models. In particular, the Deep Convo-
lutional Neural Networks (CNN) have been proven most
suitable for image-based problems as they are exceptional
at feature learning without needing any domain expertise.
Until now there have been many successful implementations
of data driven surrogate models in the various applications of
CFD. Some of them are, the prediction of the velocity ﬁeld
in 2D or 3D non-uniform steady laminar ﬂow using CNN
with shared encoding and seperated decoding architecture
[7]; The ﬂuid simulations in porous media using Gated U
– Net based on Pixel CNN+ [13]; Steady-State Laminar
Flow Approximation using U-Net with multiple decoders
[14]; application of CNN on the output of CFD simulations
to learn the tasks such as ﬂuid force, ﬂow prediction and
Reconstruction [15]. All the above implementations make
use of pooling along with the Convolutions layers.
Although the CNN combined with pooling excel at
learning features as hierarchical components, they fail to
generalize the features for different orientations of an object
in the image. Thus, they need huge training data set to
improve the accuracy and for better generalization. This
drawback of CNN will prove difﬁcult to build surrogate
models for ﬂuid ﬂow approximation as they require huge
training data set, which is an arduous task considering the
bottleneck of creating the data set with the help of time-
consuming CFD simulators. In that case we need a surrogate
model that would be able to produce results with similar
accuracy but at the same time, demanding lesser data for
training.
To overcome this issue, we propose the application of
Capsule Neural Networks (CapsNet) for prediction of ve-
locity ﬁeld in steady ﬂow.
A. CapsNet an Overview
Capsule Neural Networks is one of the latest discovery
in the ﬁeld of deep neural networks by Geoffrey Hinton
and team [1], [2]. The model not only classiﬁes the data
but reconstructs the original image by decoding the encoded
class vector.
The CapsNet is in a way an improvement over con-
ventional Deep Convolution Neural Networks where it
overcomes the problems of the latter such as the loss of
information due to max-pooling, lack of pose relationships
between the simple features that are responsible for gener-
ating higher-level features.
Capsules are a form of activation function which takes
input as vector and outputs a vector. i.e. activation functions
with tensor input and tensor output [9]. The vectors incor-
porate instantiation parameters, crucial for addressing pose
relationships between the features. CapsNet uses viewpoint257

For training the Capsules we have the Dynamic Routing
algorithm. In the Dynamic Routing algorithm, the weights
between the consecutive layers get adjusted based on the
extent of agreement between the inputs from the lower layer
and the outputs from the higher layer. In other words, the
lower layer capsule tends to send its output to the higher
layer capsule, whose output agrees to its input. This is
achieved by the dot product between the outputs of lower
level and higher level capsules. The detailed explanation
about the algorithm can be found in [1], [2].
CapsNets are highly capable of capturing features with all
possible orientations of the object. This makes them learn
important features with fewer data. This remarkable strength
of CapsNet particularly makes it desirable for ﬂuid ﬂow
approximation problems since producing high volumes of
training data of CFD simulations is a challenging task.
II. C APS NET ARCHITECTURE FOR FLUID FLOW
APPROXIMATION
For the implementation of the project we have followed
the boundary classiﬁcation method. We have 28 images of
cars of different shapes of 4 different classes, i.e 4 classes
of boundaries. Each class has around 5-9 images. We have
prepared data in such a way that each boundary is mapped
to its respective class label and simulated velocity ﬁeld for
training.
The architecture in Figure 1 represents our model. It
is very similar to the original architecture implemented
for the MNIST data-set, implemented by Geoffrey Hinton
and team [1]. We have used this architecture as an initial
implementation to understand the effectiveness of CapsNet
for the given problem. The architecture has two parts,
Encoder and Decoder part. The Encoder part takes the input
image and encodes the image into a 16-dimensional vector.
There will be as many 16 dimensional encoded vectors as
the number of boundary classes (In this case there are 4
classes). The decoder part has three fully connected layers
that learn to reconstruct the velocity ﬁeld by decoding the
features learned by the encoder.
A. Encoder part
 Step 1 - The image will be given as input to the model.
 step 2 - the conv1 layer followed by ReLU activation
uses 256 kernels of size 9 on the input image.
 step 3 - The primary caps layer has 32 capsule layers
each of which applies eight 9 9 256 kernels to the
input it receives. The outputs of the convolutions will
be reshaped to the vectors of size 8.
 step 4 - The vectors from the primary Caps layer are fed
to the Boundary Caps layer where the number of rows
is equal to the number of classes of the boundaries.
Each of the input vectors from the Primary Caps layer
will be multiplied by an 8 16 weight matrix to
transform the input vectors into 16-dimensional vectors
which refers to the number of instantiation parameters.
B. Decoder
 Step 1 - The output from the Boundary caps layer is
weighted and directed to each neuron of the ﬁrst FC
i.e FC1 layer.
 step 2 - The outputs from FC1 are weighted and
directed to each neuron of the 2nd FC layer i.e FC2.
 step 3 - Similar to the above steps the inputs from
second FC layers are weighted and directed to the last
FC layer which has the same number of neurons as the
number of pixels of the output image.

VI. C ONCLUSION
CapsNet requires a fraction of the data that is required by
CNN to produce similar or better results. Since we have a
lower number of hidden layers and the collection of neurons
as capsules, the model will have lesser trainable parameters
which speed up the training process. These beneﬁts are of
great importance for ﬂuid ﬂow approximation problems as
the solutions will be more accurate and can be produced
much faster than other conventional ANNs, while requiring
lesser data.260

VII. F UTURE WORK SCOPE
The model implemented here is at the primitive stage
as the concept of Capsule Neural Network is a pristine
discovery in the ﬁeld of deep neural networks. This effective
and novel concept can be adapted in various ﬁelds and one
among them is CFD. The model implemented in this work
is a classiﬁcation model. An unsupervised approach would
save the time of classifying objects.
The problem can be scaled to build a 3d ﬂuid ﬂow
approximation model that would require an optimal data
set as it is possible for CNN to learn the interpretable
representation of images using which 3d reconstruction of
image is possible [4]. Furthermore we can incorporate both
equivalence and invariance as combining both the parts
performs better than applying each alone [3].
