## Abstract: суррогат LES для городского слоя (с. 1–2)

Надёжное пространственное предсказание концентрации примеси в городском каньоне дорого для Large Eddy Simulation (LES) и недостижимо для гауссовых моделей, игнорирующих геометрию (с. 2). Обучается свёрточная суррогатная нейросеть, отображающая растровое описание идеализированной регулярной шахматной застройки (геометрия зданий, leaf-area index, дорожные источники эмиссии, ветер) на стационарное поле PM2.5 на четырёх высотах и его вертикальное среднее, на данных модели MSU-RCC LES (с. 2). На тестовом наборе суррогат достигает R² = 0.86, FAC2 = 0.75, NMSE = 0.44 и низкого смещения (FB = 0.07, mass_ratio = 0.93), удовлетворяя критериям Chang–Hanna (с. 2). Поле определяется в первую очередь источниками эмиссии и растительностью (с. 2). FiLM на векторе ветра не даёт измеримого выигрыша в контролируемом абляционном исследовании и слегка ухудшает метрику массового баланса; аугментация данных существенна (с. 2). Суррогат работает ~3.5 ms на конфигурацию города (с. 2).
