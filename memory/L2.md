# L2 — тезисы

1. Свёрточный суррогат предсказывает стационарное поле PM2.5 идеализированного городского каньона на четырёх высотах и вертикальном среднем по растровому описанию застройки, LAI, дорожных источников и ветра (с. 2).
2. На тестовом наборе суррогат достигает R² = 0.86, FAC2 = 0.75, NMSE = 0.44, FB = 0.07 и mass_ratio = 0.93, удовлетворяя критериям Chang–Hanna (с. 2).
3. Эталонные данные — LES идеализированного каньона в нейтральной стратификации: область 256×256×64 м на сетке 128×128×32, здания высотой 16 м в шахматном порядке (~6% площади) (с. 4).
4. Набор данных: 9 раскладок, 2670 симуляций, 58566 образцов; вход — растр 7×128×128, цель — концентрация на уровнях Z1, Z5, Z8, Z25 (3, 10, 16, 50 м) и средняя по высоте (с. 5).
5. Суррогат — U-Net с ~5.1×10⁶ параметрами; ветер встраивается MLP (3→128→512) и подаётся на декодер через FiLM (с. 6–7).
6. Потеря в лог-пространстве: L = MSE_w + 0.05·MAE_w + 1.0·MSE с весами w = min(exp(𝛽y), 50)/⟨min(exp(𝛽y), 50)⟩, 𝛽 = 1 (с. 8).
7. Модель приемлема при FAC2 ≥ 0.5 и NMSE ≤ 1.5; обучение AdamW (lr 10⁻⁵, batch 256) с ReduceLROnPlateau (factor 0.5, patience 5) (с. 8).
8. Базовые модели без геометрии хуже предсказания среднего: mean-field R² = −0.31, FAC2 = 0.19; nearest-wind R² = −0.72, FAC2 = 0.15 (с. 9).
9. Абляция (200 эпох): удаление аугментации вредно (R² 0.798→0.737, mass_ratio 0.865→0.832), удаление FiLM улучшает метрики (mass_ratio = 0.928) (с. 10).
10. Суррогат считает сцену за ~3.5 мс на V100 (~284 сцен/с) против ~20 мин LES — быстрее на 4–5 порядков (с. 12).
