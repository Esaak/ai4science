# Пакет ДЗ2: проверка центра шлейфа DL-суррогата

## Проверка

Окружение: Python 3.14.4, NumPy 2.5.4. Установка:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

Одна команда запуска из корня репозитория:

```bash
.venv/bin/python checks/check_hw2.py
```

Код 0: восемь синтетических тестов и проверки архива пройдены, по 25 сценам
медиана ошибки центра ≤ 10 м и не менее 20 сцен имеют ошибку ≤ 20 м.
Код 1: ошибка проверки либо правило принятия не выполнено.
`--synthetic` запускает только синтетические тесты; `--dry-run` дополнительно
проверяет архив без записи результатов. Доступ к серверу не требуется.

Дополнительный анализ: `.venv/bin/python src/hw2_uncertainty.py`.
Три seed выполняются за один запуск; это post-hoc парный bootstrap,
который не меняет правило принятия.

## Состав

- `METHOD.md`: постановка, формулы, пороги, хронология и ограничения.
- `checks/check_hw2.py`: тесты, проверка архива, метрики и вердикт.
- `fixtures/hw2/`: сохранённые поля и манифест с контрольными суммами.
- `src/hw2_uncertainty.py`: дополнительный статистический анализ.
- `results/hw2/`: результаты, вывод до/после ошибки и журнал попыток.
- `reports/hw2_report.md`: отчёт, дерево подцелей, ограничения и авторство.

## Правила работы

Работать в `hw2-work`. `main` и тег `hw1` сохраняются как прежняя сдача.
Не выполнять push и не создавать тег `hw2` без указания пользователя.
Не менять научные пороги по результатам прогона, архив и контрольные суммы данных
без отдельной задачи. Сохранять фактическое авторство, ограничения и порядок
коммитов методики и результатов. Журнал содержит только выполненные команды.
Ключи и локальное окружение в Git не включать. Пользователь 2026-11-15 разрешил
включить архив `fixtures/hw2/plumes.npz` и его манифест в репозиторий сдачи.
