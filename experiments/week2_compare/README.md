# Сравнение двух тестовых прогонов недели 2

## Что это

Архив двух независимых прогонов агента над одной и той же задачей —
посчитать метрики качества суррогата LES по пяти сценам из
`data/edison_cache/top_fields.npz` для двух моделей (`p_combo` и
`p_прежняя`). Прогон `run_with` использовал полный `AGENTS.md` как
договор; прогон `run_without` — тот же проект, но с удалённым
`AGENTS.md`, задача поставлена словами.

## Откуда взялось

Исходные копии лежали в `../week2_runs/` вне проекта. Перенесены в
`experiments/week2_compare/` для хранения вместе с остальными
результатами.

## Структура

```
week2_compare/

│   ├── results/

│   │   └── metrics.py

└── run_with/              ← копия проекта с AGENTS.md
    ├── results/
    │   ├── metrics.json
    │   └── metrics_table.md
    ├── src/
    │   └── metrics.py
    ├── diary.md           ← запись в журнал (только run_with)
    └── git_log.txt        ← вывод git log той копии
```

Не скопированы: `.venv/`, `.git/`, `data/`, `library/` — они
восстанавливаются или уже есть в проекте.

## Чем отличались

| Аспект | run_without (без AGENTS.md) | run_with (с AGENTS.md) |
|---|---|---|
| Задача | «Посчитай метрики качества предсказания по данным в data/» (словами) | «Выполни цель из AGENTS.md» |
| AGENTS.md | удалён | на месте, 9,5 Кб |
| Число шагов | 16 | 20 |
| Вызовы проверки | 2 (самостоятельно) | по ходу работы |
| Коммиты | нет | два (работа + diary.md) |
| diary.md | не создан | создан, запись о задаче |
| Лишние файлы | compute_metrics.py в корне | нет |
| Код проверки | 0 | 0 |
| Числовые метрики | совпали побитово | совпали побитово |

Ключевые выводы:
- Без AGENTS.md агент восстановил спецификацию из `checks/check.py`
  (раздел 7 AGENTS.md: «утечка спецификации через проверку»).
- С AGENTS.md агент соблюдал запреты (не пытался ssh/scp/git push),
  делал коммиты и вел diary.md.
- Раздел 4 «Запреты» — без него агент не знал ограничений; с ним —
  ни одного нарушения.
- Раздел 6 «Память» — без него diary.md не создан; с ним — запись
  добавлена.
